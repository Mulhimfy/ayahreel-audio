# ayahreel-audio

A backup copy of publicly available Quran recitation files, kept so the
AyahReel app keeps working when a publisher's site is unreachable. The
files are in this repository's releases, byte for byte as their
publishers serve them.

The recitations belong to their reciters and to the sites that publish
them: [EveryAyah](https://everyayah.com), [mp3quran.net](https://mp3quran.net),
[QuranicAudio](https://quranicaudio.com), [Tarteel](https://tarteel.ai),
[King Saud University](https://quran.ksu.edu.sa), [archive.org](https://archive.org)
and [Way2Quran](https://way2quran.com). The verse text is
[quran.com](https://quran.com)'s.
